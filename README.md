# RPGCore Wiki v0.0.1 — Documentation Edition

A text-first, image-free RPGCore wiki. Includes all seven class paths, interactive Rank I → Rank II → Rank III progression, 147 active skill references, upgrade comparisons, quests, configuration and installation documentation.

## Preview
Open `index.html` in a browser, then select **Classes & Ranks**. All assets are local.

## GitHub Pages
Upload the contents of this folder to your repository root. Enable GitHub Pages under Settings → Pages → Deploy from a branch → main → /(root).

The wiki is documentation only; it does not modify the RPGCore plugin.
